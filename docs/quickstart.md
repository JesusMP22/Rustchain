# RustChain — 5-Minute Quickstart Guide

## What is RustChain?

RustChain is a blockchain where **old hardware earns more than new hardware**. A PowerBook G4 from 2003 earns 2.5x more than a modern Threadripper.

## Install in 30 seconds

```bash
curl -sSL https://raw.githubusercontent.com/Scottcjn/Rustchain/main/install-miner.sh | bash
```

## Start mining

```bash
rustchain-miner --wallet your-wallet-name
```

## Check your balance

```bash
curl -fsS "https://rustchain.org/wallet/balance?miner_id=your-wallet-name"
```

## Multipliers

| Hardware | Multiplier |
|----------|------------|
| Modern x86_64 | 0.8x |
| Apple Silicon M1-M4 | 1.05-1.2x |
| PowerBook G4 (2003) | 2.5x |
| Power Mac G5 (2003) | 2.0x |
| DEC VAX (1977) | 3.5x |
| ARM2 (1987) | 4.0x |

## Supported Platforms

Linux (x86_64, ppc64le, aarch64) · macOS (Intel, Apple Silicon, PowerPC) · Windows · FreeBSD · Raspberry Pi

## Why RustChain?

- **$0 entry cost** — use any existing computer
- **E-waste prevention** — old machines get new life
- **6 anti-VM checks** — only real hardware earns
- **Decentralized** — no cloud VMs allowed
- **Sustainable** — 500W total for 16+ vintage machines
